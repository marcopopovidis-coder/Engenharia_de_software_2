Atividade Prática – Introdução à Engenharia de Requisitos

1. Quem utilizará o sistema?
A secretaria da escola.

2. Cite 3 requisitos funcionais (o que o sistema deve fazer).

* Cadastrar alunos no sistema.
* Registrar a frequência dos alunos.
* Lançar e consultar as notas dos alunos.

3. Cite 2 requisitos não funcionais (como o sistema deve funcionar).

* O sistema deve ser seguro, permitindo acesso apenas a usuários autorizados.
* O sistema deve ser rápido e estar disponível durante o horário de funcionamento da escola.

4. Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.**
É importante porque ajuda a identificar as necessidades dos usuários, evita erros durante o desenvolvimento e garante que o sistema atenda aos objetivos da escola.
